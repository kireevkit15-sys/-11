# 02. Техническая архитектура

## 1. Стек

### 1.1. Фронтенд
- **Next.js 16** (App Router, React Server Components, Turbopack по умолчанию). На момент скаффолда (май 2026) `create-next-app@latest` выдаёт уже 16-ю версию вместо запланированной 15 — это совместимое обновление, оставляем.
- **React 19.2** (поставляется с Next.js 16).
- **TypeScript 5.9** (strict + noUncheckedIndexedAccess + noImplicitOverride + noFallthroughCasesInSwitch).
- **Tailwind CSS 4.2** + **shadcn/ui** (New York, Neutral base, CSS Variables — токены через `@theme inline` в `globals.css`).
- **Framer Motion** — для микроанимаций (добавим на этапе доработки дизайна).
- **next/image** — оптимизация изображений (AVIF + WebP fallback).
- **next/font** — локальная подгрузка шрифтов (no FOIT/FOUT).

### 1.2. Контент / CMS
- **Strapi 5.44** (Headless CMS, self-hosted в Docker на том же VPS).
- Контент-типы (созданы в скелете): `article`, `case-study`, `service`, `team-member`, `faq`, `glossary-term`, `review`, `fsi-deadline`. Все с draftAndPublish.
- В dev — SQLite (быстро для разработки), в prod — PostgreSQL через переменные окружения.
- Превью контента до публикации (preview mode Next.js).
- Роли: `admin` (полный доступ), `editor` (контент-менеджер: пишет статьи, без настроек).

### 1.3. Бэкенд (минимальный)
Next.js Route Handlers (`app/api/*`) для:
- `/api/leads` — приём форм, валидация, сохранение в БД, триггер бота.
- `/api/calculator` — расчёт стоимости (логика на сервере, цены — из Strapi).
- `/api/subscribe` — подписка на чек-лист / напоминания.
- `/api/revalidate` — webhook от Strapi для on-demand ISR.

### 1.4. База данных
- **PostgreSQL 16** (managed, например Supabase или Neon — для скорости старта).
- ORM: **Drizzle** (легче и быстрее Prisma, отличная типизация).
- Таблицы: `leads`, `subscribers`, `calculator_logs`, `analytics_events`.

### 1.5. Telegram-бот
- **grammY** (TypeScript) — деплоим как отдельный процесс или serverless function.
- Хранение состояния — в той же PostgreSQL.
- Функции:
  - Приём заявок с сайта, отправка в чат РОПа с inline-кнопками.
  - Подписка пользователей на напоминания о дедлайнах ФСИ.
  - Cron-рассылка напоминаний.

### 1.6. Инфраструктура

| Компонент | Решение | Обоснование |
|---|---|---|
| Хостинг Next.js | **VPS (Selectel/TimeWeb)** + Docker + Caddy | Решение заказчика — всё на собственном сервере. Полный контроль, российская юрисдикция, нет зависимости от Vercel и блокировок. |
| Хостинг Strapi | Тот же VPS (Docker Compose) | Один сервер для всего — экономия и упрощение деплоя. |
| Хостинг БД | PostgreSQL в Docker на том же VPS | Та же причина. Бэкапы — внешние (S3 / отдельный диск). |
| Хостинг бота | Тот же VPS (Docker Compose) | Экономия. |
| CDN | Cloudflare (бесплатный план) | Кэш статики, защита от ботов. |
| Хранилище медиа | **S3-совместимое** (Selectel Object Storage / Yandex Object Storage) | Не раздуваем диск VPS. |
| Email | **SMTP** Yandex 360 / Mail.ru для бизнеса | Уведомления, рассылка лид-магнитов. Резерв для TG-бота. |
| Домен и SSL | accounting-diva3d.ru (или новый, если решит заказчик) + Let's Encrypt | Авто-обновление сертификата. |

> **Важно по 152-ФЗ:** все персональные данные граждан РФ должны храниться на серверах в РФ. По решению заказчика всё (включая Next.js) разворачивается на одном VPS в РФ — это упрощает соответствие закону.

### Минимальные требования к VPS (стартовая конфигурация)

| Параметр | Значение | Обоснование |
|---|---|---|
| vCPU | 4 | Next.js (SSR) + Strapi + PostgreSQL + бот = 4 процесса под нагрузкой |
| RAM | 8 GB | Strapi сам ест 1–1.5 GB, PG ~1 GB, Next.js 0.5–1 GB, запас |
| Диск | 80 GB SSD | Контент + медиа + БД + Docker образы |
| Канал | от 100 Мбит/с | С запасом под раздачу медиа |
| ОС | Ubuntu 24.04 LTS | Стандарт для Docker, долгая поддержка |
| Бэкап | Внешний S3 (Selectel Object Storage) | Ежедневный дамп БД + медиа |

Хостер: **Selectel** или **TimeWeb Cloud** (оба — РФ, оба умеют S3, оба адекватны по цене ~2000–3500 ₽/мес). Окончательно решаем при покупке.

## 3. Стратегия рендеринга

| Тип страницы | Метод | Обоснование |
|---|---|---|
| Главная | SSG + ISR (revalidate 1h) | Контент меняется редко, нужна максимальная скорость и SEO. |
| Лендинги услуг | SSG + ISR (revalidate 1h) | Аналогично. |
| Блог-статья | SSG + on-demand revalidate (webhook из Strapi) | Мгновенное обновление при публикации. |
| Список статей | SSG + ISR (revalidate 10min) | |
| Кейсы | SSG + ISR | |
| Калькулятор | Client Component | Интерактивный, состояние на клиенте. Данные о ценах — fetch при загрузке. |
| Формы | Client Component + Server Action | Server Action для отправки. |
| Календарь ФСИ | SSG + ISR (revalidate 1d) | Дедлайны меняются редко. |
| Юр. документы | SSG | Статика. |

## 4. Производительность (целевые показатели)

- **Lighthouse Performance:** ≥ 95 на десктопе, ≥ 90 на мобильных.
- **Core Web Vitals:**
  - LCP < 2.5s
  - CLS < 0.1
  - INP < 200ms
- **Размер JS-бандла на главной:** < 100 KB gzipped.
- Все изображения через `next/image`, формат AVIF.
- Шрифты — `font-display: swap`, локально, preload.
- Минимум сторонних скриптов, аналитика — через next/script с `strategy="afterInteractive"`.

## 5. Безопасность

- **CSP** (Content Security Policy) — strict, с nonce для inline-скриптов.
- **HSTS, X-Frame-Options, X-Content-Type-Options** — через `next.config.js`.
- **Rate limiting** на API формам — через middleware (`@upstash/ratelimit` или собственный на Redis).
- **Защита форм:**
  - Honeypot-поле (невидимое для людей, заполняется ботами).
  - Время заполнения формы (если < 2 сек — отбрасываем).
  - Опционально: hCaptcha (лучше reCAPTCHA — без Google-зависимости).
- **Секреты:** только через переменные окружения, никогда в репозитории.
- **HTTPS** обязательно, редирект с HTTP.
- **Регулярные обновления** зависимостей (Dependabot или Renovate).
- **Бэкапы БД:** автоматически ежедневно, retention 14 дней.

## 6. Аналитика и мониторинг

| Инструмент | Зачем |
|---|---|
| **Яндекс.Метрика** | Основная аналитика, Вебвизор, цели, карта кликов, отчёты по UTM. |
| **Google Tag Manager** | Универсальный контейнер для счётчиков (если решим добавлять). |
| **Sentry** | Ошибки на фронте и бэке. |
| **Vercel Analytics / Plausible** | Real User Monitoring (RUM) для Core Web Vitals. |
| **UptimeRobot** | Внешний мониторинг доступности сайта и бота (5-минутный пинг). |

**События в Метрике (цели):**
- `consultation_lead_form` — заявка отправлена с быстрой формы.
- `consultation_dikidi_click` — клик по кнопке записи в dikidi.
- `calculator_completed` — пользователь дошёл до результата калькулятора.
- `calculator_to_lead` — после калькулятора оставил заявку.
- `lead_magnet_download` — скачал чек-лист.
- `tg_subscribe` — подписался на TG-бот напоминаний.
- Скролл-цели (25%, 50%, 75%, 100%) на главной для оценки глубины.

## 7. CI/CD

- Репозиторий: GitHub (private).
- **CI:** GitHub Actions — линт, type-check, build, e2e-smoke (Playwright).
- **CD:**
  - `main` → автодеплой Next.js на Vercel/VPS (preview на pull request).
  - Strapi и бот деплоятся через `docker compose pull && up -d` по webhook от GitHub.
- Защита `main`: PR + ревью обязательны.

## 9. Решения и открытые вопросы

### Принятые решения
- ✅ **Хостинг:** всё на одном VPS в РФ (Next.js + Strapi + PostgreSQL + бот в Docker Compose).
- ✅ **Домен:** регистрируем новый, более короткий (имя уточним отдельно). Со старого `accounting-diva3d.ru` ставим 301-редиректы.
- ✅ **Email-рассылки на старте:** только транзакционные через SMTP. Полноценный email-маркетинг — фаза 2 (Unisender / Sendsay).
- ✅ **Cookie-баннер:** расширенный с категориями.

### Ещё нужно уточнить
- **Имя нового домена** (заказчик подбирает).
- **Хостер VPS:** Selectel или TimeWeb Cloud (выбираем при покупке, по цене и доступности нужной конфигурации).
- **Поддомен для Strapi-админки:** `admin.<домен>` или путь `/admin` с базовой авторизацией?
  - Рекомендация: отдельный поддомен `admin.<домен>` + IP-whitelist на Caddy.
