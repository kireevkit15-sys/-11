# 03. Постраничная структура

> Каждая страница описана в формате: **цель → блоки → контент → поведение**. Формат «компонент-первый» — каждый блок переиспользуем.

## Глобальные элементы (на всех страницах)

### Шапка (Header)
- Логотип ДИВА (слева, ведёт на главную).
- Меню: Услуги · Тарифы · Кейсы · Блог · Контакты.
- Справа: телефон (кликабельный) + кнопка-CTA «Бесплатная консультация» (открывает модал записи).
- На мобильных: бургер-меню + sticky-кнопка консультации.
- При скролле — компактная версия (тоньше, с фоном).

### Подвал (Footer)
- Колонки:
  1. Логотип + краткое описание + соц. сети (VK, Telegram, YouTube, RuTube).
  2. Услуги (ссылки).
  3. Компания (О нас, Кейсы, Блог, Контакты).
  4. Юр. документы (Политика, Согласие, Оферта).
- Реквизиты компании: ООО «...», ИНН, ОГРН, юр. адрес.
- Копирайт + год (автоматически).

### Sticky-CTA
- **Десктоп:** фиксированная кнопка справа внизу с текстом «Записаться на консультацию» (появляется после прокрутки 30% страницы).
- **Мобильные:** bottom navigation с двумя кнопками: «Позвонить» / «Записаться».

### Модал «Запись на консультацию»
- Открывается с любой кнопки CTA.
- Два таба:
  1. **Выбрать удобное время** — встроенный виджет dikidi.net (`<iframe>`).
  2. **Перезвоните мне** — простая форма: Имя + Контакт (телефон или TG) + чекбокс согласия на ПДн.
- После отправки формы — экран благодарности с UTM-сохранением, событие в Метрику.

### Cookie-баннер
- Появляется при первом визите.
- Категории: «Необходимые» (всегда вкл.), «Аналитика», «Маркетинг».
- Кнопки: «Принять всё» / «Только необходимые» / «Настроить».
- Сохранение выбора в localStorage на 12 месяцев.

## 1. Главная страница `/`

**Цель:** за 5 секунд донести УТП, за 30 секунд — закрыть на консультацию или провести по странице с накоплением доверия.

### Блок 1.1. Hero
- **Слева (60%):**
  - Заголовок H1 (крупный): **«Бухгалтерия для стартапов и отчётность по грантам ФСИ»**.
  - Подзаголовок: «Занимайтесь своим проектом — отчёты сделаем мы. Бесплатная консультация 30 минут с экспертом по ФСИ».
  - Список из 3 пунктов с иконками: «5 лет на рынке» / «N+ клиентов» / «₽X млн привлечённых грантов».
  - Две CTA рядом: **«Записаться на консультацию»** (primary) и **«Посмотреть тарифы»** (ghost, скролл к блоку 1.3).
  - Мелким текстом: «Без обязательств · Ответим на ваши вопросы · 94% клиентов остаются с нами».
- **Справа (40%):**
  - Видео-приветствие основателя (YouTube/RuTube embed с автоплеем без звука + кнопкой play).
  - Под видео — превью: «Смотрите 1 минуту, узнайте главное».

### Блок 1.2. Полоска доверия
Узкая горизонтальная полоса под hero, тёмный фон.
- 4 цифры с подписями: `5 лет` / `N клиентов` / `₽X млн грантов` / `94% конверсия консультации в договор`.
- На мобильных — карусель.

### Блок 1.3. Услуги / Тарифы
- Заголовок H2: «Выберите тариф под вашу систему налогообложения».
- 4 карточки в ряд (на мобильных — стек):
  1. **УСН** — для большинства стартапов
  2. **ОСН** — для крупных и НДС-чувствительных
  3. **АУСН / ПСН** — для микробизнеса
  4. **ФСИ-отчётность** — отдельный продукт (highlight badge «Наша специализация»)
- Каждая карточка:
  - Название тарифа + краткое описание (1 строка).
  - Цена «от ₽X / мес» (крупно).
  - Список 4–5 пунктов «что входит».
  - Кнопка «Подробнее» → раскрывает полный список (accordion на мобильных, hover на десктопе).
  - Кнопка «Заказать» → модал записи с предзаполненной темой.

### Блок 1.4. Калькулятор стоимости
- Заголовок H2: «Сколько будет стоить бухгалтерия для вашего стартапа?»
- Подзаголовок: «3 шага, 30 секунд — и вы знаете цену без звонка».
- Шаги (визуально слева — список шагов с прогрессом, справа — текущий шаг):
  1. **Система налогообложения:** УСН Доходы / УСН Доходы-Расходы / ОСН / АУСН / ПСН (radio-группа с описанием каждой).
  2. **Сотрудники:** 0 / 1–3 / 4–10 / 10+ (chips).
  3. **Операций в месяц:** до 20 / 20–100 / 100–500 / 500+ (chips).
  4. **(Опц.)** Чекбокс «Получили грант ФСИ» — если да, добавляется отдельный блок с ценой ФСИ-отчётности.
- Результат:
  - Большая цифра «Ваш тариф: от ₽X / мес».
  - Что входит (динамический список).
  - Две кнопки: «Записаться на консультацию» (primary) и «Получить расчёт на email» (форма с email).
  - Мелким текстом: «Точная цена обсуждается на консультации с учётом специфики проекта».

### Блок 1.5. Разовые услуги
- Заголовок H2: «Разовые услуги».
- Сетка 3×N карточек с иконками. Примеры:
  - Регистрация ООО / ИП «под ключ»
  - Восстановление учёта
  - Закрытие года
  - Подготовка к проверке ФНС
  - Сопровождение проверки ФСИ
  - Бухгалтерская консультация (платная, 60 мин)
- Каждая карточка: название + 1 строка описания + цена + кнопка «Заказать».

### Блок 1.6. О компании / Команда
- Заголовок H2: «5 лет специализации на стартапах и ФСИ».
- Слева: 2 абзаца текста об истории компании, миссии, специализации.
- Справа: ключевые цифры компании.
- Ниже: «Наша команда» — карточки сотрудников (4–8 человек):
  - Фото (квадрат).
  - Имя + должность.
  - На hover/click — раскрывается карточка с биографией: образование, опыт, специализация, цитата.
  - Иконки сертификатов / квалификаций.

### Блок 1.7. Кейсы
- Заголовок H2: «Что мы сделали для клиентов».
- 4 карточки с верхним превью и возможностью «Все кейсы →» в правом верхнем углу.
- Каждая карточка кейса:
  - Логотип/название клиента (с разрешения).
  - Тематика (тег: «ФСИ», «УСН», «Восстановление» и т.д.).
  - Заголовок результата (например, «Защитили 3 этапа гранта ФСИ Старт-1 без замечаний»).
  - 2–3 ключевых цифры (например, «₽5 млн грант», «12 мес сопровождения», «0 замечаний от ФСИ»).
  - Кнопка «Читать кейс» → `/cases/[slug]`.

### Блок 1.8. Отзывы
- Заголовок H2: «Что говорят клиенты».
- Карусель из 6–10 отзывов:
  - Аватар + имя + проект клиента.
  - Текст отзыва (3–5 строк).
  - Источник: «Отзыв из ВК / Видео / Письменный».
  - Кнопка «Смотреть все отзывы» под каруселью → ведёт в группу ВК или на отдельную страницу.

### Блок 1.9. Контент / Видео
- Заголовок H2: «Полезный контент о ФСИ и бухгалтерии».
- Сетка 3 видео (последние с YouTube/RuTube, через `next/image` обложка + lightbox по клику).
- Под сеткой: ссылки на соц. сети с иконками и количеством подписчиков.

### Блок 1.10. FAQ
- Заголовок H2: «Частые вопросы».
- Аккордеон 8–12 вопросов, разбитых на категории-табы: «О компании» / «Бухгалтерия» / «ФСИ» / «Цены и оплата».
- Schema.org `FAQPage` разметка для SEO.
- Под FAQ: «Не нашли ответ? Спросите эксперта на консультации» + CTA.

### Блок 1.11. Лид-магнит
- Заголовок H2: «Чек-лист: 12 ошибок грантополучателя ФСИ + календарь дедлайнов 2026».
- Слева: иллюстрация PDF-обложки.
- Справа: краткое описание + форма (email или TG-username) + кнопка «Скачать бесплатно».
- После отправки: «Чек-лист отправлен на ваш email. Подпишитесь на наш TG-бот, чтобы не пропустить дедлайны → [кнопка]».

### Блок 1.12. Контакты
- Заголовок H2: «Свяжитесь с нами».
- Слева: компактная форма (имя + контакт + сообщение) с чекбоксом согласия.
- Справа: контакты (телефон, email, TG, VK), адрес, время работы, карта (Яндекс.Карты embed).

## 2. Лендинги услуг (`/usn`, `/osn`, `/ausn`, `/fsi-otchetnost`, `/registratsiya-ooo` и т.д.)

**Цель:** ловить целевой трафик из Яндекс.Директ и SEO по узкому запросу.

Структура каждого лендинга:
1. **Hero** — заголовок под конкретный запрос («Бухгалтерия на УСН для IT-стартапов»), CTA, доверительные цифры.
2. **Кому подходит** — 3–4 пункта с иконками.
3. **Что входит** — детальный список услуг этого тарифа.
4. **Цена** — таблица: количество сотрудников / операций → цена.
5. **Калькулятор** (тот же компонент, предзаполненный системой НО).
6. **Кейсы** — 2–3 релевантных кейса.
7. **Отзывы** — 3 релевантных отзыва.
8. **FAQ** — вопросы по конкретной услуге.
9. **CTA-блок** — финальный.

## 3. Блог `/blog`

### Список статей `/blog`
- Hero: «База знаний по бухгалтерии и ФСИ».
- Фильтры по рубрикам: ФСИ / Налоги / ООО / Гранты / Все.
- Поиск по статьям.
- Карточки статей: обложка + рубрика + заголовок + анонс (3 строки) + дата + время чтения.
- Пагинация (или infinite scroll).

### Статья `/blog/[slug]`
- Хлебные крошки.
- H1 + рубрика + дата + время чтения + автор (с фото).
- Содержание (Table of Contents) — sticky слева на десктопе.
- Контент: markdown из Strapi (заголовки H2/H3, списки, таблицы, цитаты, код, картинки, embed-видео).
- Кнопки шеринга (TG, VK, Telegram, копировать ссылку).
- В конце: CTA-блок «Нужна консультация по этой теме? Запишитесь бесплатно».
- Похожие статьи (3 шт. по тегам).
- Schema.org `Article` разметка.

## 4. Кейсы `/cases`

### Список `/cases`
- Hero + краткое описание подхода.
- Фильтры по тегам: ФСИ / Восстановление / Стартап / Регистрация и т.д.
- Карточки кейсов (как на главной).

### Кейс `/cases/[slug]`
- H1 (например, «Сопровождение гранта ФСИ Старт-1 для биотех-стартапа N»).
- Шапка: логотип/название клиента + тег + период работы.
- Блок «Задача» — 1–2 абзаца.
- Блок «Решение» — детали с иллюстрациями.
- Блок «Результат» — большие цифры + цитата клиента.
- Связанные услуги (карточки) → перелинковка.
- Финальный CTA.

## 5. Глоссарий `/glossary`

- Hero + описание.
- Алфавитный указатель (ссылки А Б В Г … Я).
- Список терминов (карточками или таблицей).
- Каждый термин: `/glossary/[term]` — отдельная страница с подробным объяснением (для SEO long-tail).

## 6. Календарь дедлайнов ФСИ `/fsi-calendar`

- Hero: «Календарь дедлайнов ФСИ 2026 — не пропустите ни одного отчёта».
- Фильтры: по типу гранта (Старт / Развитие / Коммерциализация) и по этапу.
- Таймлайн: список ключевых дат, отсортированных по дате.
- Каждая запись: дата + название этапа + что нужно сдать + ссылка на статью с инструкцией.
- CTA: «Подпишитесь на TG-бот — пришлём напоминание за 14 / 7 / 1 день».
- Кнопка экспорта в iCal (Google Calendar, Apple Calendar).

## 7. Контакты `/contacts`

- Сетка контактов: телефон / email / TG / VK / WhatsApp.

## Дизайн-направление (черновое)

Финальный дизайн делает дизайнер, но фиксируем направление, чтобы все были на одной волне:

- **Тональность:** профессионально, дружелюбно, без «банковской сухости» и без «детских иллюстраций». Лаконично и уверенно.
- **Цветовая схема:** базируется на брендбуке заказчика. Предположительно: тёмно-синий/тёмно-зелёный + белый + один акцентный цвет (CTA).
- **Типографика:** один шрифт без засечек для UI (например, Inter / Manrope) + один акцентный для заголовков (например, Unbounded / Geologica).
- **Иллюстрации:** минимум стоковых фото, максимум — фото команды, скриншоты документов, иконки в едином стиле.
- **Анимации:** аккуратные fade-in при скролле, hover на интерактивных элементах. Никакого «вау-эффекта ради вау-эффекта».
- **Адаптивность:** mobile-first. Тестируем на iPhone SE (узкий экран) и iPad (для гибридных юзкейсов).
- **Тёмная тема:** не делаем в первой версии (B2B-аудитория, в основном desktop в light mode; усложнит дизайн).
