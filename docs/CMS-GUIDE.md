# 📘 РУКОВОДСТВО ПО УПРАВЛЕНИЮ САЙТОМ ДИВА ЧЕРЕЗ CMS

## О CMS (Strapi)

Сайт управляется через **Strapi** — систему управления контентом (CMS). 
Адрес админки: `https://cms.divadiva.ru/admin` (или аналогичный, предоставленный ранее).

---

## 📋 КАК ЗАПОЛНИТЬ CMS

### 1. Вход в админку

1. Откройте `https://ваш-cms/admin`
2. Введите логин и пароль (созданы при первой настройке)
3. В левом меню выберите **Content Manager**

---

### 2. Типы контента

#### 📊 Услуги (`Services`)
**Что заполнять:**
| Поле | Описание | Пример |
|------|----------|--------|
| `title` | Название услуги | "Бухгалтерия для УСН" |
| `slug` | URL-имя (автозаполняется) | usn-accounting |
| `tax_system` | Система налогообложения | УСН-Д, ОСН, АУСН, ФСИ |
| `base_price` | Цена (целое число) | 7900 |
| `includes` | Перечень работ (JSON) | ["Декларация по УСН", "Бухгалтерская отчётность", ...] |
| `is_highlighted` | Выделить карточку? | true для ФСИ-услуги |
| `key` | Уникальный ключ | usn-2024 |

**JSON для `includes`:**
```json
[
  "Декларация по УСН",
  "Бухгалтерская отчётность",
  "Расчёт по страховым взносам",
  "6-НДФЛ",
  "Отчёт СЗВ-ТД"
]
```

**Пример данных:**
1. АУСН — 5 900 ₽/мес
2. УСН — 7 900 ₽/мес
3. ОСН — 8 900 ₽/мес
4. ФСИ — от 35 000 ₽/грант

#### 👥 Команда (`Team Members`)
**Что заполнять:**
| Поле | Описание | Пример |
|------|----------|--------|
| `full_name` | ФИО | "Ольга Чекаленко" |
| `position` | Должность | "Главный бухгалтер" |
| `photo` | Фото (загрузить через Media Library) | файл.jpg |
| `bio` | О себе | "Оперативно решаю сложные задачи..." |
| `education` | Образование | "Бакалавр, Томский политех..." |
| `specialization` | Специализация | "Главный бухгалтер, 12 лет опыта" |
| `quote` | Цитата (необязательно) | "Доверяй, но проверяй" |
| `years_experience` | Опыт (число) | 12 |
| `is_founder` | Основатель? | true только для Павла |
| `sort_order` | Порядок сортировки | 1, 2, 3... |

**Как добавить фото:**
1. В редактировании сотрудника нажмите на поле `photo`
2. Выберите "Media Library" → "Upload new media"
3. Загрузите фото (рекомендуемый размер: 400×500px)

#### 📈 Статистика (`Site Statistics`)
**Что заполнять:**
| Поле | Описание | Пример |
|------|----------|--------|
| `key` | Уникальный ключ | "startups-total" |
| `value` | Число | 780 |
| `suffix` | Суффикс (необязательно) | "+" |
| `label` | Подпись | "стартапов сопровождали" |
| `caption` | Описание | "Технологические компании во всех 8 федеральных округах" |
| `sort_order` | Порядок | 1 |

**Пример данных:**
1. 780+ стартапов сопровождали
2. 460 стартапов в работе сейчас
3. 1100+ бесплатных консультаций

#### 🏛️ Столпы доверия (`Trust Pillars`)
**Что заполнять:**
| Поле | Описание | Пример |
|------|----------|--------|
| `number` | Номер | "01" |
| `title` | Название принципа | "Надёжность" |
| `content` | Текст принципа | "Наша компания помогает стартапам..." |
| `quote` | Цитата (необязательно) | "Подкрепляем эффективность..." |
| `hue` | Цветовой оттенок (0-360) | 250 (фиолетовый) |
| `sort_order` | Порядок | 1 |

**Рекомендуемые значения `hue`:**
- 01 — 250 (фиолетовый)
- 02 — 270 (синий)
- 03 — 290 (розовый)
- 04 — 230 (индиго)
- 05 — 215 (голубой)
- 06 — 260 (пурпурный)

#### 🎬 Видео (`Videos`)
**Что заполнять:**
| Поле | Описание | Пример |
|------|----------|--------|
| `title` | Название | "О компании ДИВА" |
| `video_id` | ID видео (из YouTube) | "3vvjytkHV3s" |
| `platform` | Платформа | youtube, rutube |
| `description` | Описание | "Приветственное видео..." |
| `views` | Количество просмотров | 1200 |
| `duration` | Длительность | "0:58" |
| `sort_order` | Порядок | 1 |
| `key` | Уникальный ключ | "intro-video" |

**Как найти video_id YouTube:**
1. Откройте видео на YouTube
2. Скопируйте часть после `v=` в URL:
   - URL: `youtube.com/watch?v=3vvjytkHV3s`
   - video_id: `3vvjytkHV3s`

### 3. Публикация контента

1. После редактирования нажмите **Save**
2. Для публикации нажмите **Publish** (зеленая кнопка справа)
3. Чтобы снять с публикации — **Unpublish**

**Важно:** После изменений сайт автоматически обновится через 1-5 минут (кеширование).

## 🛠️ ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК

### Сайт показывает старые данные
1. Подождите 5-10 минут (кеш)
2. Или перезагрузите страницу Ctrl+Shift+R (Hard Refresh)

### Не отображаются услуги/команда
1. Проверьте, что записи **опубликованы** (Publish)
2. Проверьте `sort_order` — если 0, запись может не показываться

### Фото не загружается
1. Формат: JPG, PNG, WebP (не PDF, не GIF)
2. Размер: до 5 МБ
3. Попробуйте переименовать файл на английские символы
