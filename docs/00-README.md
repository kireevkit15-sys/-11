# Сайт ДИВА — бухгалтерия для стартапов

Документация проекта по разработке нового сайта для бухгалтерской компании ДИВА (специализация — стартапы и отчётность по грантам Фонда содействия инновациям).

**Текущий сайт:** https://www.accounting-diva3d.ru/ (на Tilda, фактически визитка).
**Цель проекта:** превратить сайт из визитки в основной канал привлечения и квалификации клиентов через таргетированную рекламу и SEO.

## Ключевые решения

- **Стек:** Next.js 15 (App Router) + TypeScript + Tailwind CSS + Headless CMS (Strapi).
- **Хостинг:** один VPS в РФ (Next.js + Strapi + PostgreSQL + TG-бот в Docker Compose). Без Vercel.
- **Домен:** новый, более короткий (имя уточняется). Со старого `accounting-diva3d.ru` — 301-редиректы.
- **Запись на консультацию:** dikidi.net (онлайн-календарь) + быстрая форма «перезвонить» с уведомлением в Telegram РОПу.
- **CRM:** уведомления в TG-бот → ручная синхронизация с YouGile (на старте), интеграция с YouGile API (фаза 2).
- **Подход к запуску:** сначала скелет на дефолтном/минимальном дизайне с контентом из текущего сайта, затем итеративно дорабатываем брендинг, фото, кейсы, копирайтинг.
- **Приоритет:** качество и долгосрочный результат, а не скорость запуска.

## Ключевые KPI

1. Конверсия посетитель → заявка на консультацию: цель **≥ 4%** на холодном трафике, **≥ 8%** на тёплом (ретаргет).
2. Конверсия консультация → клиент: сохранить текущие **94%**.
3. Core Web Vitals: **LCP < 2.5s, CLS < 0.1, INP < 200ms** на мобильных.
4. SEO: топ-10 Яндекса по 30+ ключам по тематике ФСИ за 6 месяцев.
