# Сайт ДИВА — бухгалтерия для стартапов

Перезапуск корпоративного сайта бухгалтерской компании ДИВА, специализирующейся на сопровождении стартапов и грантов ФСИ. Стек: Next.js (фронтенд), Strapi (CMS), grammY (Telegram-бот для приёма заявок и уведомлений) и сопутствующая инфраструктура.
